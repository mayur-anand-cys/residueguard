2. CORE MATH & LOGIC ENGINE (MUST BE IMPLEMENTED)
==================================================
You must implement this exact logic in the "FPO Dashboard" tab. When a user changes an input, the verdict must recalculate instantly.

Data Dictionary (Hardcode this exact data):
const chemicals = {
  "Azoxystrobin": { phi: 15, dt50: 10, mrl_fssai: 2.0, mrl_eu: 2.0, eu_approved: true },
  "Mancozeb": { phi: 21, dt50: 2, mrl_fssai: 0.5, mrl_eu: 0.01, eu_approved: false },
  "Carbendazim": { phi: 30, dt50: 14, mrl_fssai: 0.1, mrl_eu: 0.01, eu_approved: false }
};

Calculation Logic (Minimum Safe Interval):
k = Math.log(2) / dt50
dose_adj = Math.log(dose_applied / label_dose) / k
market_adj = Math.max(0, Math.log(mrl_fssai / mrl_target) / k)
MSI = Math.ceil(phi + dose_adj + market_adj)

Verdict Logic:
1. If Market is "EU" and eu_approved is false -> Verdict = "DO_NOT_USE" (Rose theme). Reason: "Banned in EU. Default MRL 0.01 mg/kg."
2. If days_to_harvest < MSI -> Verdict = "DELAY_HARVEST" (Amber theme). Reason: `Wait ${MSI - days_to_harvest} more days. True MSI: ${MSI} days.`
3. If days_to_harvest >= MSI -> Verdict = "SAFE" (Emerald theme).
